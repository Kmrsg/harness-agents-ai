# Форма создания обращения — пример входной спецификации

Пользователь вводит название обращения и нажимает «Создать».
Название обязательно; строка из пробелов считается пустой.
Backend проверяет данные и возвращает идентификатор созданного обращения.
Frontend отображает подтверждение успешного создания.

Это учебная спецификация, а не готовое ТЗ для production.
Аналитик должен выявить недостающие продуктовые решения до реализации.
В реальной задаче specPath может указывать на OpenSpec spec.md.
