# Исправления по независимому ревью MVP

Исходные находки и воспроизведения: [mvp-review-2026-11-02.md](mvp-review-2026-11-02.md).
Ниже — изменения реализации по всем девяти подтверждённым проблемам. Корпоративные
MCP/API и реальный LLM CLI по-прежнему требуют проверки на рабочем ПК.

Новые тесты находятся в `tests/workflow/reliability.test.ts`,
`tests/agents/saved-artifacts.test.ts`, `tests/agents/transport.test.ts` и
`tests/review/recovery.test.ts`. Они запускаются обычным npm test вместе с прежним
набором. Проверки корпоративных сервисов в эти тесты не входят.

Контрольный прогон: **125 passed, 0 failed, 0 skipped** на Node.js 22 с внешним
OpenSpec CLI. Проверка типов и форматирования также пройдена. Включены проверки
общей защиты ветки для retry-delivery и восстановления уже принятого PR push.

## Изменения настроек

- runnerInput по умолчанию stdin. Harness запускает LLM CLI с --output-format json
  и передаёт AgentRequest в stdin. Проверьте такой headless-вызов на вашей версии CLI.
- runnerInput=argv оставлен для коротких запросов и добавляет -p <prompt>.
  Порог 64000 байт фиксированный и не повышается через maxInputBytes.
- maxInputBytes по умолчанию 4000000 байт UTF-8. Это размер всего сериализованного
  запроса, не лимит токенов модели; содержимое не обрезается молча.
- maxOutputBytes остаётся отдельным пределом stdout + stderr. При его превышении
  доступный префикс вывода сохраняется, но результат процесса остаётся ошибкой.

Готовые примеры обновлены в [work-pc-setup.md](work-pc-setup.md) и
`examples/harness.config.json`.

## Совместимость сохранённых запусков

Manifest артефактов обязателен для их повторного использования. Старым результатам
без digest не выдаётся новая гарантия целостности задним числом. Полная миграция
старых checkpoint/approval не добавлена; ограничения описаны в
[continuation.md](continuation.md). Исправления не разрешают обходить review,
изменение одобренных файлов или исчерпанный бюджет доработок.

Следующая проверка готовности — сквозной запуск с рабочими LLM CLI, MCP и
идемпотентными корпоративными адаптерами. Локальные тесты не подтверждают доступы
и совместимость конкретной внутренней сборки CLI.
