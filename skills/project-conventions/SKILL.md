# Project conventions

Read [the knowledge index](../../knowledge/index.md) and select the domain relevant
to the current task. Read the matching files before making a plan; search within
that domain for the affected components or behavior when it contains many files.
Reference the source path in the plan so the implementer can retrieve the same rule.

The starter knowledge is not an authoritative corporate standard. Prefer explicit
project conventions and surface conflicts with requirements or MCP rules. When no
rule exists, record the gap rather than inventing an organizational convention.

This skill finds conventions. It does not authorize Git publication or tracker updates.
