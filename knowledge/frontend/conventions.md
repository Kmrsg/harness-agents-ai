# Начальные frontend-соглашения

- Повторно используйте компоненты и способы работы с API существующего проекта.
- Для асинхронных действий учитывайте loading, success, error и повторную отправку.
- Не придумывайте API внутренних библиотек: найдите реализацию или запросите Codebase MCP.
- Получайте применимые правила UI MCP до изменения UI; фиксируйте источник в плане.
- Следуйте существующим требованиям доступности, типизации и форматирования проекта.
