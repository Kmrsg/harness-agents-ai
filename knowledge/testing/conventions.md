# Начальные соглашения тестирования

- Проверяйте наблюдаемое поведение и исходные критерии приёмки.
- Для каждого критерия приводите сценарий, фактический результат и доказательство.
- Проверяйте ошибки, права доступа и взаимодействие frontend/backend, когда они затронуты.
- Указывайте, какие проверки выполнены с реальными сервисами, а какие — с заглушками.
- Невыполненная проверка не считается успешной.
