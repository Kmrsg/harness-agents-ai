# Начальные backend-соглашения

- Соблюдайте существующий API-контракт и формат ошибок проекта.
- Валидируйте входные данные на сервере; frontend-валидация не заменяет серверную.
- Используйте существующие механизмы аутентификации и авторизации.
- Изменения данных и миграции явно описывайте в плане до реализации.
- Не помещайте секреты и персональные данные в ответы API и логи.
