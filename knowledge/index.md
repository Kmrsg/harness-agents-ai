# Индекс конвенций

Это начальная локальная база знаний, не официальные правила организации.
Перед реальным запуском дополните её конвенциями рабочего проекта.

| Область | Файл | Когда читать |
|---|---|---|
| Frontend | frontend/conventions.md | Компоненты, формы, состояние UI, интеграция API |
| Backend | backend/conventions.md | Endpoint, валидация, доступ, данные |
| Testing | testing/conventions.md | Проверки критериев, негативные сценарии, отчёт |

При добавлении темы создайте отдельный Markdown-файл и добавьте строку индекса.
Harness подгружает выбранный домен; база не требует отдельного репозитория.
Если правила конфликтуют с ТЗ или MCP, укажите источники конфликта и запросите решение.
